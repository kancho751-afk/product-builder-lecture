# Lotto Number Generator

## Overview

This is a simple web application that generates random lottery numbers.

## Features

*   Generates 6 unique random numbers between 1 and 45.
*   Allows generating multiple sets of numbers at once.
*   Displays the generated numbers in a visually appealing way with animations.
*   Modern, responsive, and interactive design.
